Activity Report writes your daily stand-up from your GitHub activity, your meetings, your reminders and your notes, ready to paste in Slack, Google Chat or anywhere else.

Getting started

  1. Create a classic personal access token on GitHub with the repo and read:org scopes: create a token.
  2. If your organization uses single sign-on (SAML), click Configure SSO next to the token on GitHub and authorize the organization.
  3. Paste the token when the app asks for it, or later in Settings › GitHub.

Common questions

The report shows no activity from my organization. Fine-grained tokens only see an organization's private repositories once the organization has approved them, so the app asks for a classic token. With a classic token, check that it is authorized for your organization's single sign-on (step 2).

My meetings or reminders are missing. Allow Activity Report in System Settings › Privacy & Security › Calendars (or Reminders). For Google meetings, add your Google account in System Settings › Internet Accounts with Calendars turned on.

Links are not clickable when I paste in Google Chat or Slack. Use the Slack / GChat format and the Copy to clipboard button (⇧⌘C): it copies rich text along with the plain text.

Where is my data? On your Mac only; see the Privacy Policy.
